# Definición de Hecho (Definition of Done)

Una historia de usuario se considera **terminada** cuando cumple todos estos
criterios:

1. El código compila sin errores (`php -l` en todos los `.php`).
2. La funcionalidad funciona en navegador (Chrome/Edge/Firefox).
3. Los filtros aplican a KPIs, gráficos, tabla y exportaciones.
4. El PDF se genera con normas APA y gráficos no negros.
5. El CSV se abre correctamente en Excel en español (acentos OK).
6. El código está comentado en español.
7. No hay errores en la consola del navegador.
8. Se actualiza el README si cambia el comportamiento.
9. Los cambios se suben a GitHub (`main`).
